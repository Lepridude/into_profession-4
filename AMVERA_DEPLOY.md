# Развёртывание на Amvera

В проекте есть Procfile для Gunicorn на `$PORT` (по умолчанию 8000).

1. Сначала опубликуйте оба Loginom-сервиса и проверьте URL.
2. Создайте приложение в панели Amvera.
3. Загрузите файлы проекта без `.env`, `.venv`, `.git` и кэша Python.
4. В «Переменные и секреты» добавьте `LOGINOM_URL`, `LOGINOM_CHECK_URL`, `LOGINOM_TIMEOUT=45`, `GIGA_KEY`, `GIGA_MODEL=GigaChat-2`, `SECRET_KEY`, `COOKIE_SECURE=1`, `FLASK_DEBUG=0`.
5. В конфигурации контейнера установите `containerPort=8000`.
6. Выполните сборку, затем запуск.
7. Проверьте `/health`, авторизацию с существующим ID, отказ для несуществующего ID и полный анализ.
8. Остановите приложение после проверки для экономии баланса; включите перед 17.12.2026.

Само создание приложения в панели Amvera требует авторизации в аккаунте. В текущей сессии такого доступа нет, поэтому домен и запуск нельзя считать выполненными.
