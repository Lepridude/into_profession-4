# Развёртывание на Amvera

В корне проекта подготовлен `amvera.yml`:

```yaml
meta:
  environment: python
  toolchain:
    name: pip
    version: "3.11"
run:
  command: gunicorn --bind 0.0.0.0:8000 app:app
  containerPort: 8000
```

## Перед загрузкой

1. Опубликуйте оба Loginom-сервиса и внесите их реальные URL в `.env`.
2. Проверьте живой вызов GigaChat локально.
3. Убедитесь, что в `.env` заданы `GIGA_KEY`, `LOGINOM_URL`, `LOGINOM_CHECK_URL` и `SECRET_KEY`.

## В панели Amvera

1. Создайте приложение в Amvera.
2. Выберите загрузку проекта через интерфейс или привязку GitHub-репозитория. При загрузке через интерфейс добавьте все файлы проекта, включая `amvera.yml` и `requirements.txt`, но не загружайте `.env` как обычный файл кода.
3. В разделе «Переменные» импортируйте `.env` или добавьте значения вручную. Для `GIGA_KEY` и `SECRET_KEY` используйте тип «секрет».
4. Убедитесь, что конфигурация указывает `containerPort=8000`.
5. Выполните сборку, затем запуск. Amvera использует команду Gunicorn из `amvera.yml`.
6. Привяжите домен и проверьте `https://ВАШ-ДОМЕН/health`, авторизацию с существующим ID, отказ для несуществующего ID и полный анализ истории.
7. После проверки остановите приложение для экономии баланса; включите перед 17.12.2026.

Само создание приложения в панели требует авторизации в аккаунте Amvera. В текущей сессии доступа к этому аккаунту нет, поэтому домен и запуск здесь не созданы.
